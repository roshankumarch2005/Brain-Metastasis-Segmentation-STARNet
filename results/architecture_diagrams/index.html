Method 1: Inter-Level Feature Consistency Regularization

Teacher-Student Deep Supervision with Detached Anchor & Quadratic Hinge Discrepancy

Vector SVG High-Res PNG
Mechanism: Full-resolution decoder stage $d_0$ acts as the spatial teacher. Its gradients are detached ($p_0.\text{detach}()$) to prevent coarse representations from degrading fine boundaries. Deeper stages ($d_1..d_5$) are trilinearly upsampled and penalized via a quadratic hinge function $\max(0, |\text{diff}| - T_r)^2$ with tolerance $T_r = 0.20$. In Add All, all 5 levels are constrained; in the Ablation, only the deepest bottleneck $d_5 \to d_0$ is constrained.

Method 2: Decoder-1 Half-Resolution Bypass Architecture

Eliminating Input Skip Noise via Sub-Voxel Trilinear Reconstruction

Vector SVG High-Res PNG
Mechanism: Level 0 skip connections inject raw MRI acquisition noise (ringing, vascular gradients) into Decoder 0, creating ragged borders. Method 2 completely bypasses Decoder 0, extracting the primary segmentation from Decoder 1 ($H/2 \times W/2 \times D/2$, $2\times$ receptive field) and upsampling to native resolution using mathematically continuous sub-voxel trilinear interpolation. Slashes parameters by 22% while providing peak fidelity on micro-metastases.

Method 3: 3D Depthwise Separable Convolutions & Dimension Factorization

Decoupling 3D Spatial Filtering from Cross-Channel Linear Combination

Vector SVG High-Res PNG
Mechanism: Replaces dense 3D convolutions ($27 \cdot C_{\text{in}} \cdot C_{\text{out}}$) with a decoupled two-stage operation: 3D Depthwise spatial filtering ($3\times3\times3$, $\text{groups}=C_{\text{in}}$) followed by InstanceNorm + LeakyReLU, followed by 3D Pointwise linear projection ($1\times1\times1$). Achieves ~93% parameter reduction per layer, shrinking network footprint to 1.23M–3.8M parameters and enabling real-time edge execution.
